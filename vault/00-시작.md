# AWS CLF-C02 학습 데스크

## 매일 20분 흐름

1. [로컬 문제 풀이](http://127.0.0.1:8765)에서 **복습 예정** 문제를 먼저 푼다.
2. 답을 고르면 풀이 시간이 자동 기록된다. 틀렸거나 오래 걸렸다면 해당 개념 노트의 **이해와 비교** 및 **자주 틀리는 지점**을 읽는다.
3. **내 오답**에 내가 혼동한 두 개념을 한 문장으로 적는다.
4. 다음날 복습 예정 문제로 같은 구별법을 다시 확인한다.

AI 비교 해설을 요청한 오답은 [[Review/00-오답-지도|오답 복습 지도]]에서 카테고리와 학습서 장별로 다시 볼 수 있다. 각 노트의 **내 말로 다시 정리**를 채워서 AI 설명과 내 이해를 대조한다.
