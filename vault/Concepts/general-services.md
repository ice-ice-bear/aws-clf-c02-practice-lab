# AWS 서비스 선택

## 한 줄 구별법

요구 사항의 핵심 단어를 찾고 각 서비스가 해결하는 문제를 공식 시험 범위와 대조한다.

## 이해와 비교

- 요구 문장에서 동사를 먼저 찾는다: 저장, 분석, 전달, 권한 부여, 탐지, 이전, 자동화. 그다음 데이터 형태와 운영 책임 범위를 확인한다.
- 두 서비스가 모두 가능해 보이면 문제의 제약 조건을 찾는다. 예를 들어 실시간 여부, 중단 허용, 관계형 데이터, 공유 파일, 규정 준수 증거 등이 결정적 단서다.
- 이 노트는 자동 분류가 어려운 문항의 임시 모음이다. 오답이 쌓이면 더 구체적인 개념 노트로 옮기고 분류 규칙을 개선한다.

## 자주 틀리는 지점

낯선 서비스 이름을 외우기 전에 시험 범위에 포함되는지 확인한다.
