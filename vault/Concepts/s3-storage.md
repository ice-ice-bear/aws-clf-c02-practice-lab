# S3와 스토리지 클래스

## 한 줄 구별법

S3는 객체 스토리지이며 접근 빈도와 복구 요구에 따라 클래스를 고른다.

## 이해와 비교

- S3는 객체를 버킷에 저장한다. 파일 시스템처럼 블록을 직접 수정하거나 EC2에 디스크로 붙이는 목적과 다르다.
- 스토리지 클래스 선택에는 접근 빈도, 검색 지연 허용, 보관 기간을 함께 본다. Standard는 자주 접근하는 데이터, Standard-IA는 덜 자주 접근하지만 빠른 검색이 필요한 데이터의 후보이다.
- Glacier 계열은 장기 보관과 검색 시간의 균형을 따져 고른다. 버전 관리는 덮어쓰기·삭제 사고에 대비하고, 수명 주기 규칙은 클래스 전환·만료를 자동화한다.

## 자주 틀리는 지점

저렴한 저장 단가만 보지 않는다. 검색 요금과 최소 보관 기간도 선택에 영향을 준다.
