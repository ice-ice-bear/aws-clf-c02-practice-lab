# 공동 책임 모델

## 한 줄 구별법

AWS는 클라우드의 기반 시설을, 고객은 선택한 서비스에 따른 데이터·설정을 책임진다.

## 이해와 비교

- AWS는 데이터센터, 물리적 서버, 기반 네트워크 같은 '클라우드 자체의 보안'을 맡는다. 고객은 데이터, IAM 권한, 애플리케이션과 서비스 구성을 관리한다.
- EC2에서는 고객이 게스트 OS 패치와 방화벽 구성까지 맡는다. 관리형 서비스로 갈수록 AWS가 운영하는 범위가 넓어지지만, 고객의 데이터 보호와 접근 권한 책임은 남는다.
- 암호화 기능을 AWS가 제공해도 사용할지, 어떤 키와 접근 정책을 쓸지는 고객의 설정 문제다.

## 자주 틀리는 지점

'AWS가 관리형 서비스를 운영한다'와 'AWS가 내 데이터의 접근 정책을 결정한다'를 혼동하지 않는다.

## 스스로 확인

EC2 게스트 OS 패치와 데이터센터 물리 보안은 각각 누가 담당하는가?
