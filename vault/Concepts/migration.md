# 마이그레이션·전송

## 한 줄 구별법

온라인 전송, 물리 장치 전송, 데이터베이스 이전의 목적을 구별한다.

## 이해와 비교

- DataSync는 파일·객체 데이터를 온라인으로 이전·동기화할 때, Snow Family는 네트워크 전송이 어렵거나 대용량 물리 이전이 필요할 때 검토한다.
- DMS는 데이터베이스 이전을 지원한다. Storage Gateway는 온프레미스 환경과 AWS 스토리지를 연결하는 하이브리드 접근에 쓴다.
- 이전 계획은 데이터 크기, 네트워크 대역폭, 중단 허용 시간, 소스 유형을 먼저 확인한다. 단순 복사와 DB 엔진 전환은 다른 문제다.

## 자주 틀리는 지점

물리 장치 전송, 온라인 파일 동기화, 데이터베이스 이전을 모두 같은 서비스로 답하지 않는다.
